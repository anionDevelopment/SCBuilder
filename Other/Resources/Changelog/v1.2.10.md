# Release notes

## Changes
- Updated dependencies.
- Added the new codeunit `SCTaskRunnerAndroid`: a permanently-running container-image, analogous to `SCTaskRunnerWindows`/`SCTaskRunnerMacOS`, that builds Android-app build-steps (flutter `appbundle`-builds) on behalf of remote clients. Unlike the Windows-/macOS-runners it runs as a container (not natively), because the Android-SDK/NDK - unlike a Windows- or macOS-toolchain - works inside a Linux-container.
- Removed the Android-SDK/NDK (command-line-tools, platform, build-tools, ndk) from the SCBuilder-image: Android-app-building moved completely to `SCTaskRunnerAndroid`. Flutter itself stays in SCBuilder for its other targets (web/windows/linux-desktop). This requires a released ScriptCollection-version that contains the corresponding `TFCPS_CodeUnitSpecific_Flutter`-change (delegating the `appbundle`-target to the Android-runner) and a deployed/configured `SCTaskRunnerAndroid`-instance before it takes effect end-to-end; see the codeunit's ReadMe for how to run it.
