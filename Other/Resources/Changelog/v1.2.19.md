# Release notes

## Changes

- Added the status-report for `scrais`: the image contains the helper `scrais-agent-status` and the hook-configurations for claude, codex, copilot, opencode and vibe, so that `scrais` of ScriptCollection can show the state of a sandboxed agent in herdr. The helper does nothing without the event-folder of `scrais`, so builds are not affected. See the section "Status-report to herdr" of the article `RunAgentInSandbox` of ScriptCollection.
