# Release notes

## Changes

- SCTaskRunnerAndroid: updated ScriptCollection to 4.4.73, whose SCTaskRunnerServer sets the environment-variables a client gives to a job (header `X-Environment-Variables`) for the program of that job. A productive build of an android-codeunit uses this to sign the app-bundle with the upload-key.
- SCTaskRunnerAndroid, SCTaskRunnerIOS, SCTaskRunnerMacOS, SCTaskRunnerWindows: the runners provide the endpoint `GET /metrics` (basic-auth required), which returns the amount of currently running jobs as the Prometheus-gauge `sctaskrunner_running_jobs`. This is implemented in the SCTaskRunnerServer of ScriptCollection 4.4.73, so SCTaskRunnerIOS, SCTaskRunnerMacOS and SCTaskRunnerWindows require `scriptcollection>=4.4.73` now.
