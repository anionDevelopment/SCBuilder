# Release notes

## Changes

- Added support for the `TrustedRootCA`-mechanism of ScriptCollection (introduced in scriptcollection v4.4.54, see the matching changelog-entry there for the full description). A containerized build (`scbuildcodeunits -c`, `scbuildcodeunitsc`) now trusts additional root-CA-certificates which the host declares via `TrustedRootCA_<name>_Path`-, `TrustedRootCA_<name>_Content`- or `TrustedRootCA_<name>_ContentBase64`-environment-variables - needed when the build pulls dependencies from a privately hosted registry (for example an internally hosted gitlab-nuget-source) whose certificate-chain is not publicly rooted. Concretely:
  - `EntryPoint.sh` now scans `/Workspace/RootCAs/*.crt` (mounted by scriptcollection from the `_Path`-variables) and the `TrustedRootCA_*_Content`-/`_ContentBase64`-environment-variables at container-start, writes the certificates into `/usr/local/share/ca-certificates/` and runs `update-ca-certificates` once before `exec "$@"`. A failing `update-ca-certificates` aborts the container-start, so a build never runs with an incomplete trust-store. Multiline PEM-values are handled correctly by iterating `${!TrustedRootCA_@}` instead of parsing the output of `env`.
  - `EntryPoint.sh` additionally sets `SSL_CERT_FILE`/`REQUESTS_CA_BUNDLE`/`CURL_CA_BUNDLE`/`PIP_CERT`/`NODE_EXTRA_CA_CERTS` to `/etc/ssl/certs/ca-certificates.crt`, so python-requests, pip, curl and node (which otherwise fall back to their builtin bundle, which does not know the injected CAs) honor the injection too. The system-bundle is a strict superset of the vendored bundles, so setting these unconditionally is safe.
  - The `Dockerfile` now installs `ca-certificates-java` (so the `jks-keystore`-update-hook mirrors every `update-ca-certificates`-run into the shared JKS at `/etc/ssl/certs/java/cacerts`) and replaces Temurin's own `${JAVA_HOME}/lib/security/cacerts` by a symlink to that shared location, so the JVM reads from the shared JKS transparently. This way the JVM-trust-store is covered without a second mechanism.
